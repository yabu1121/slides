# 表紙の図案

`slides.md` の表紙にある `風景` のブロックに、ここの SVG の中身を貼り替える。
色は `var(--c-*)` のまま書いてある。トークンを変えれば図案の色も追従する。

| ファイル | 中身 |
| --- | --- |
| `nature.svg` | 山と木。落ち着いた雰囲気 |
| `tech.svg` | データセンターの街並みと紙飛行機。技術寄りで少し浮かれた雰囲気 |

どちらも `viewBox="0 0 580 280"` で揃えてあるので、そのまま差し替えられる。
新しく作るときも同じ viewBox にする。

画像で差し替えたいときは `public/` に置いて
`<img src="/cover.png" class="w-[690px]">` に入れ替える。
